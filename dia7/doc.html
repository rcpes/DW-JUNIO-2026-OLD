Documentación del Proyecto: CINE HD

1. Descripción de las Secciones de la Página

La página web CINE HD es una plataforma de streaming o catálogo multimedia que se divide en las siguientes secciones clave:

  • Cabecera (Header): Contiene el logotipo de la marca alineado a la izquierda con un diseño tipográfico imponente y un menú de navegación (Nav) a la derecha con enlaces a Inicio, Películas, Series y TV Online.
  • Banner Principal (Portada): Un elemento visual a lo ancho de la pantalla que muestra una imagen destacada promocional (en la captura, una ilustración de Superman).
  • Bloque de Series Recientes: Una galería cuadriculada que expone tarjetas con las portadas, títulos y años de lanzamiento de producciones como Cabo de Miedo, Silo, Sugar, entre otras.
  • Bloque de Películas Recientes: Una cuadrícula gemela dedicada al formato cinematográfico que lista estrenos recientes organizados simétricamente.
  • Barra de Mensaje y Pie de Página (Footer): Un banner inferior de texto que invita a descubrir contenido online, seguido por los créditos de derechos reservados sobre un fondo rojo sólido.

2. Aspectos Visuales Generales

El diseño de la aplicación web adopta la estética oscura o "Dark Mode", altamente optimizada para plataformas de entretenimiento multimedia nocturno:

  • Paleta de Colores: Predomina el negro puro (#060606) de fondo y grises oscuros (#191919) en tarjetas, usando el Rojo corporativo (#ba0000) como color de acento vibrante en el footer, bordes de títulos y estados interactivos.
  • Tipografía y Efectos: Se implementa la familia de fuentes Arial / Arial Black combinada con sombras de texto (text-shadow) que facilitan la legibilidad sobre fondos oscuros.
  • Interactividad Visual: Las tarjetas cuentan con un efecto de transformación al pasar el cursor (hover), elevándose suavemente mediante translateY(-8px) y aumentando su sombra paralela para crear sensación de profundidad.

3. Organización del Proyecto (Estructura de Archivos)

Según el espacio de trabajo actual, el proyecto está estructurado de manera limpia y modular bajo el directorio raíz dia7/:

dia7/
├── css/
│ ├── main.css Compilado
│ ├── main.css.map
│ └── main.scss Código Fuente
├── images/
│ ├── [Todas las portadas .jpg/webp]
│ └── C30251.jpg (Banner)
├── js/
│ └── main.js
└── index.html

Se destaca el uso del preprocesador SASS (.scss), el cual centraliza los estilos antes de ser compilados a un archivo CSS plano legible por el navegador.

4. Técnicas de Maquetación y Diseño Responsive

El proyecto implementa soluciones modernas de CSS moderno para asegurar flexibilidad:

  • Flexbox: Utilizado en la barra de navegación para distribuir los ítems del menú de forma horizontal de manera equidistante empleando la propiedad display: flex y un espaciado controlado mediante gap: 1rem.
  • CSS Grid (Diseño Adaptativo): La galería multimedia está construida sobre un sistema de rejilla fluida:
    grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
    Esto permite que el diseño sea 100% responsive; las tarjetas se reordenarán y expandirán automáticamente dependiendo de si el usuario visualiza la web desde un smartphone, tablet o pantalla de escritorio sin romper la estructura.

5. Reutilización de Componentes y Estilos

Para optimizar el código y evitar la redundancia, se han tomado decisiones arquitectónicas eficientes:

  • Clases Clon: El bloque de películas y el bloque de series comparten exactamente las mismas clases estructurales (.series y .galeria-series). Esto garantiza que cualquier cambio visual afecte equitativamente a ambos bloques sin duplicar código CSS.
  • Tarjetas Modulares: La clase .tarjeta actúa como un componente agnóstico; no le importa si contiene información de una película o serie, recicla de forma idéntica las dimensiones de imagen, paddings y transiciones.
