Práctica de Scroll y Position Relative

El uso de inset en CSS es una forma más limpia y compacta de definir propiedades de posicionamiento como top, right, bottom y left en un solo lugar. Funciona cuando se usa junto con position: absolute, relative, fixed o sticky.

scroll-snap es una funcionalidad de CSS que permite que el contenido “se enganche” o alinee automáticamente a una posición específica cuando el usuario hace scroll. Esto mejora la experiencia de usuario al ofrecer una navegación fluida y controlada, especialmente útil en carruseles, secciones de página o listas horizontales.
