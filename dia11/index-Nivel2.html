Estructuración del Documento

¿Qué es el HTML Semántico?

Consiste en usar etiquetas que describen claramente el contenido que encierran, lo que significa que el HTML semántico promueve una web más clara, accesible y eficiente para todos los usuarios.

Etiquetas del Nivel 2

En este nivel estamos implementando contenedores especializados. Por ejemplo, la etiqueta <header> identifica el encabezado, mientras que <footer> identifica el pie con información legal o de contacto.
